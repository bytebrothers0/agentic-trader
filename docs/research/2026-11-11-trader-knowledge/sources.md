## Where sources disagree

- **CHoCH scope**: S3/S4 say CHoCH is specifically *internal* structure break against trend (external break = MSS/BOS-flip); looser sources call any first counter-trend break a CHoCH. → The library teaches: CHoCH against *internal* structure is the early warning; against *external* (with displacement) it is the shift. Both labelled.
- **OB invalidation**: wick vs close (S14: wick = mitigation, close = invalidation; some SMC variants use wick-through as invalidation). → Teach the stricter body-close rule, note the divergence.
- **Asian KZ start**: 19:00 vs 20:00 NY time (S10 comment threads). → Give both, prefer 20:00 as the ICT-cited value.
- **NY AM KZ end**: 09:00 vs 10:00 (S10 sources differ). → Teach 07:00–10:00 with the 09:50 macro as the high-probability core.
- **Does SMC "work"**: S18/S19/S20 say no edge in aggregate / only filtered variants survive; practitioner sources (S1–S14) assume it works. → The library's stance: these are *frames for reading order flow*, not proven edges; confluence + selectivity + invalidation-first is what the evidence supports.
