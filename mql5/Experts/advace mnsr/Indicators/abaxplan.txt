## Specs + expected results

**B3 `MSNR_ABX_FreshZone.mq5`** *(built, v1.00)* — 3-state lifecycle + LL/UL band (P02-03)
- Band `[LL, UL]` per 2-candle level (UL = close line, LL = sweep/OB low;
  mirror). States: FRESH (never touched) / WICK_TOUCHED (tradable half,
  needs sweep) / BODY_TOUCHED (dead unless full break flips role, I2
  parity). `UseCount` max 2; DailyGap exception (gap > ATR + prior
  reaction > ATR) lifts the cap. `ValidBuy = Close > LL` (wick under OK).
- Expected: second wick touches still marked tradable-derated; body
  touches kill the zone; gap-exception zones flagged exempt.

**B2 `MSNR_ABX_Classic.mq5`** *(built, v1.00)* — V/A reactions + touch counter (P02 p18-22)
- ClassicV: `close[i-1] < S && open[i] >= S-tol && close[i] > open[i]`
  (wick pierce < 0.3 ATR or it is a sweep, not classic). ClassicA mirror.
  No-retest: touch==1 + displacement away (body > ATR) + no return N bars.
  Type1: ≥2 rejections + mid-rally to key level; Type2: no rejection but
  liquidity sweep before (both = strongest). MicroSweep: prior-candle
  H/L pierce + close-back (P02 p22 scope 1) alongside swing scope 2.
- Touch counter per zone: wick touches without displacement; >3 -> `WEAK`
  (halve size / stronger confirm, P01 §3.4). `ZoneStrength = sweep + hold`.
- Expected: V/A arrows only on true reclaim shapes; WEAK tags on
  over-touched lines; Type1/2 labels where earned.

**B5 `MSNR_ABX_OCLZone.mq5`** *(built, v1.00)* — acceptance zones + session (P04-05)
- Zone `[min(close_k, open_k+1) .. max]` on displacement candles only
  (`body > 1.5 ATR`, doji rejected). Birth session tagged
  (Asia 0.5 / London-NY 1.0 / overlap 1.5); Asia needs LTF MSS + sweep.
- States virgin/retested/broken/flipped (I2-shape lifecycle on OCL).
  Stack score: +1 virgin/retest-reject, +1 SNR overlap (0.25 ATR),
  +1 session London/NY, +1 displacement size. FVG/TL overlap left to EA
  (E6/PHX4 objects read at scoring time, not duplicated here).
- Expected: zones only on real displacement candles; Asia zones marked
  derated; retest+rejection tagged Tradable.

**B1 `MSNR_ABX_CECluster.mq5`** *(built, v1.00)* — candle CE + mids magnet (P07)
- CE = (H+L)/2 on displacement/engulf/BOS candles only (body/range/ATR
  filter; Asia derated). OBmid = origin-candle body mid (P01 body rule).
  FVGmid read from E6-shape mini-scan. Cluster = [min..max] of mids
  within 0.2 ATR -> `MAGNET` label; singles scored 0.5.
- Control rule: bull CE holds while closes stay above; body close beyond
  = loss of control (flip bias). ≥3 crosses in 20 bars = chopped -> fair
  value, dead (P07 §4/§6 table).
- Expected: mids only on displacement candles; clusters at real magnets;
  chopped mids gray out after 3 crosses.

**B7 `MSNR_ABX_CloseTL.mq5`** *(built, v1.00)* — respected close trendlines (P06)
- Anchored on closes (Close1->Close2), wick-confirm; ≥3 touches,
  R² > 0.85 on log-price, anchored to HTF key zones (no micro-swing
  forcing). Spacing score (maxGap/minGap < 1.5 strongest; shrinking gaps
  = exhaustion warning). Above-SNR bull / below-SNR bear bias tag.
- Expected: fewer, higher-quality lines than PHX4; spacing/quality in
  tooltips; exhaustion warnings before reversals.

**B4 `MSNR_ABX_QMX.mq5`** *(built, v1.00)* — QM phases + X-point (P03-04, P06 §3-4)
- 4-step detection (HH/HL/weak-high/break/retest-zone, mirror) on
  closes + wicks; classifies QMR (reversal playbook), QMM (fake QML
  break: wick beyond + close back), QMC (fake HH/LL + break).
- Quality gate: BOS_ATR ≥ 0.8, retest delay ≥ 3 bars, confirm in
  {Engulf, Pin, OB50}, hesitation evidence pre-BOS (range contraction
  or wick expansion) else tag continuation-not-QM (P04 p36 mindset).
- Shoulder (QML) lines; QML-TL proximity triple + QMX geometric
  TL×level intersection + engulf gate (E1-shape mini-check).
- Expected: phases labeled correctly; fake legs marked not entered;
  X-points rare and high-weight.

**B6 `MSNR_ABX_HiddenBase.mq5`** *(built, v1.00)* — HTF twins + LTF probe (P04-05)
- Twins: two same-color HTF candles, opens/closes clustered (20% tol).
  On birth, CopyRates-drill the twin window on 2 LTFs: sub-detectors
  OB / V-shape / accumulation-range / volume-shift / sweep.
  `SubScore ≥ 2` -> tradable base box; else `HOLLOW` watch-only.
- Expected: twinpauses flagged on HTF; boxes only where LTF hides real
  content; hollow twins visibly dismissed.

**B8 `MSNR_ABX_SMT.mq5`** *(built, v1.00)* — lie detector (P08)
- Inputs: traded symbol + `InpPairSymbol` (default XAGUSD for XAUUSD),
  whitelist enforced with warning outside it, Corr>0.70 gate on 60-bar
  returns, 0.3-ATR divergence tolerance, ±2-bar swing alignment.
- States NONE / BULL_DIV / BEAR_DIV + `follow-the-holder` bias arrow +
  fake-extreme line (SL side). Filter, not entry (book explicit).
- Expected: divergences only when correlated; fake leg named; quiet
  otherwise.

**B9 `MSNR_ABX_AMDX.mq5`** *(built, v1.00)* — session cycle timer (P08-09)
- Session boxes (Asia/London 02:00-08:30/NY 09:30 inputs, server-tuned):
  A = range (ADX<20, range<0.5 ATR), M = sweep of A extreme + return ≤5
  bars, D = displacement body>1.5 ATR + BOS, X = post-D chop. A-vs-X by
  sequence, M-vs-break by return hold + SMT-shape (B8 confirms).
- Phase label per day + M-point / D-impulse markers. London = signal,
  NY = execution timing flags.
- Expected: one phase at a time, in order; variation depths tolerated
  with reclaim rule; X never confused with A.

**B10 `MSNR_ABX_DayProfile.mq5`** *(built, v1.00)* — bias + profiles (P09)
- Bias: HTF PD position + ERL-swept flags -> LONG/SHORT/NONE + target
  pool price (E4/E5 primitives recomputed, not read).
- Profiles: P1 trend (London displ. + NY cont.), P2 NY reversal, P3
  Judas (spike 0.2 ATR + wick>60% + return ≤3 bars), P5 S&D
  (day range < 0.7 ATR_D1 + both sides swept + no displacement close).
  S&D -> `EQ-only, half size` mode tag; Judas -> fade-side arrow with
  CE/OCL entry note. (SMT confirm layered from B8 at EA score time.)
- Expected: bias + profile stamped by mid-London; Judas/S&D caught on
  textbook days; premium-BOS traps labeled per PD gate.

**B11 `MSNR_ABX_Fibo.mq5`** *(built, v1.00)* — Abay ruler + shelf anchor (P10)
- Anchor low to H4 key overlapping displacement origin within tol
  (pragmatic 2-of-6 shelf; full 6-vote scoring at EA). Draw OBJ_FIBO
  with exact Abay list (0, 1, 1.47, 1.55, -0.72/-0.75/-0.78, 2.235,
  2.6/2.82/2.85/2.88, 3.27, 4/4.609/4.677/4.733): entry shelf
  1.0-1.55, SL shelf -0.78, TP shelves to buyside. Never gates (+0.5).
- Expected: one anchored Fibo per HTF shelf; shelves hit as TP rails;
  -0.78 breach = invalidation, not deeper entry.
