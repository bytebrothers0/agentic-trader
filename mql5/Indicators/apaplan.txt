## Specs + expected results

**A1 `MSNR_APA_AOL.mq5`** *(built, v1.00)* — AOL boxes + phase + consumption (Parts 1, 5 §1)
- Formation: BOS breakout bar (first close-through of a 2-candle level, E2
  parity). Bullish AOL = [leg low (invalidation) .. broken resistance
  (validation/top)]; leg start = most recent opposite fractal swing (Apex
  AS logic). Mirror bear.
- Phase from deepest pullback since BOS: pullback extreme never re-enters
  the box -> `PURE`; enters but holds above invalidation -> `DIFFERENT`
  (entry modules arm only here); body close through invalidation ->
  `INVALIDATED` (box dies, gray dotted).
- Consumption (P5 §1): penetration >= 50% of box depth -> `CONSUMED`
  suffix (still tradable once, unreliable after).
- Rendering: box BOS -> now (or invalidation bar); solid validation line,
  dotted invalidation line, dotted 50% line; phase label. Most-recent cap
  (`InpMaxAOL`). No rays. Closed bars only.
- Expected: boxes at real BOS origins; labels read PURE/DIFF/CONSUMED/
  INVALID matching pullback depth; invalidated boxes terminate on breach.

**A2 `MSNR_APA_EngulfTypes.mq5`** *(built, v1.00)* — Type 1/2/3 + WOL (Part 3)
- Pair scan (c1 older, c2 newer, closed bars):
  T1 bear: both bear && `h2 > h1` && `c2 < c1.close`; box top = `h2`
  (invalidation/FMD), bottom = `c1.close`. Bull mirror.
  T2: opposite colors, body engulf (`c2.close` past `c1.open`); box =
  [`c1` extreme .. worst of `c1/c2` far wick] (note: overlaps E1's
  territory with APA geometry + type tag - the switch needs all types).
  T3: c1 near-marubozu (each wick <= `InpMarubozuPct` of range, default
  10%) + c2 body-engulfs; box = c1 body; invalidation = 2-candle extreme.
- Lifecycle (light): ACTIVE -> INVALIDATED on body close through the
  invalidation extreme. Labels `T1B/T1S/T2B/T2S/T3B/T3S`. Most-recent cap.
- WOL (Type 4, gated `InpCheckWOL`, W1+ charts): MN1 Type1-3 formations via
  CopyRates form monthly zones; a weekly Type1-3 range fully inside the
  monthly zone + overlapping time -> `WOL OK`, else monthly zone marked
  `WOL INVALID` (no weekly structure = discard per P3 §5).
- Expected: T1 only on same-color sweep pairs, T3 only on marubozu origins;
  W1 charts show WOL verdicts on monthly zones.

**A3 `MSNR_APA_Shift.mq5`** *(built, v1.00)* — shift states + FMD (Parts 2 §3, 4)
- Shift events reuse PHX2 shapes (no re-detection): shift level = last
  trend-side fractal swing; break = Shift.
- Reclaim: after a shift, body close beyond the pre-shift extreme
  (highest high since N before a bear shift, mirror) -> `RECLAIMED` label,
  original trend resumes (P4 §2.2 - the shift was LE).
- Transition/chop: opposite shift within `InpChopBars` with overlapping
  range and no BOS away -> chop box + `CHOP - STAND DOWN` (P4 §2.3).
- Inside/Outside: post-shift leg range vs prior AOL bounds -> `INSIDE` /
  `OUTSIDE` tag (P4 §3).
- FMD: thrust-extreme segment (TS bar -> CHoCH bar, extends to now while
  unbroken), labeled `FMD` = SL reference (P2 §3.1).
- Expected: shifts flagged once; reclaims flip state instead of stacking
  shifts; chop boxes sit exactly on directionless ranges.

**A4 `MSNR_APA_FTA.mq5`** *(built, v1.00)* — opposing HTF trouble areas (Part 5 §2)
- HTF 2-candle levels via CopyRates on H4 + D1 (`InpHTFs`), kept if on the
  opposing side of price (supply above for shorts-first regions and
  demand below). Nearest `InpPerSide` per TF drawn as shaded bands
  (level ± `InpBandPips`) with TF tags.
- RR readout per band: distance in pips + R-multiple vs `InpRiskPips`
  (default 10, the APA stop): `FTA H4-SUP 45p = 4.5R`. EA consumes this
  for partials/BE/skip (P5 §2 Management).
- Expected: HTF zones visible on any LTF chart, RR labels live per bar.
